# AquaDesk v0.6.7

> 发布：2026-11-01 · 下架「液态玻璃」外观 + Dock 系统图标统一纯白简约

## 一句话

界面风格从三种收成两种；Dock 自己的系统图标（启动台、品牌、Windows、我的电脑、废纸篓、文件夹）
统一改成纯白简约风，软件图标保持原样不动。

## 一、下架「液态玻璃」外观

设置 → 外观 → 界面风格里删掉「液态玻璃」卡片，只剩「经典」「透明玻璃」两种。

- `DockStyle.Liquid` 枚举值保留，只为读得懂老配置文件；`StyleIndex` 反序列化时把旧值 0 一律归到
  `LiquidClear`（透明玻璃）。
- `SettingsStore` 的一次性迁移目标也改成 `LiquidClear`，老用户升级后不会落到一个已经不存在的风格上。

## 二、Dock 系统图标纯白简约

只动系统图标，应用（exe）图标保持原样：

- 底板统一成液态玻璃质感：白 20%→5% 渐变 + 1.2px 白描边 + 左上径向反光。
- 启动台：3×3 纯白圆角方块（靠透明度拉层次，不再是九色彩色）。
- 品牌：白色胶囊 + 三个挖空点；Windows：2×2 白块；我的电脑 / 废纸篓：白线条 Canvas；
  文件夹：玻璃底 + 白色线条轮廓。

> 中途一度做过「软件图标也重绘成玻璃底 + 白色首字」（`GlassIconFactory`），
> 但用户明确「只有 dock 本身系统图标更改，其他软件的不要动」，已整块回滚删除。
