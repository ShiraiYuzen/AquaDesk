# AquaDesk v0.4.11

> 发布：2026-10-31 · 产物 `AquaDesk-0.4.11.exe`（69.6 MB，自包含单文件）· 已被 v0.6.0 取代

## 一句话

状态胶囊的下排图标没居中 —— 上排 4 格、下排 3 格时，下排整体偏右半格。
把 0.4.10 那套「共享列补空格对齐」改回「每排各自居中」，两排都压在胶囊同一条中心线上。

## 前因：0.4.10 想对齐列，反而歪了下排

0.4.10 修「上下图标对不齐」时，用的办法是让两排**共用同一套列**：窄的那排左边补空格，
把图标硬推到和宽排同一列位置上，保证「下排图标压在上排图标正下方」。

这个思路在格数差为**偶数**时是对的，但差为**奇数**时就出问题：

| 场景 | 上排 | 下排 | 共享列的结果 |
| --- | --- | --- | --- |
| 英文输入法（6 项） | 3 格 | 3 格 | 差 0，正好对齐 |
| 中文输入法（7 项） | 4 格 | 3 格 | 差 1 格，下排左空 1 格右空 0 格 → **整体偏右半格 13.5px** |

半格就是 27px 的一半，肉眼一眼能看出「下排没居中」。

## 修法：回到各自居中，但这次是真的居中

`FillRow` 不再补空格对齐列，而是：

- 每排只放自己的内容列，宽度由内容决定（`row.Width = double.NaN`）；
- 靠 `HorizontalAlignment="Center"` 让整排按自身内容宽在胶囊里居中。

两排虽然内容宽不同，但都压在同一条中心线上 —— 无论上下各几个图标，视觉上都是居中的。
之前 0.4.10 之所以改成共享列，是因为「两排各自居中」在旧实现里各排的居中基准不一致；
现在统一成「同一条中心线居中」，就既居中了、又整齐了。

## 升级注意

配置不变，不用动 `%AppData%\AquaDesk\settings.json`。纯布局修正，无数据迁移。
