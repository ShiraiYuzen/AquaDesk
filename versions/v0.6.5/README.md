# AquaDesk v0.6.5

> 发布：2026-11-01 · Dock 两个显示问题：图标被挤出屏幕、出现空白方块

## 一句话

Dock 图标多到超过屏幕时不再傻长，而是整排等比缩小保证全部可见；图标取不到时先自动重试一次，
仍不行就显示名字首字，不再留一个看不懂的空格子。

## 一、图标变多后，后面的看不见

### 原因

`UpdateWindowWidth()` 只做加法，没有任何上限：

```
窗口宽 = 图标数 × (图标边长 + 间距) + 分隔线 + 内边距 + 放大预留
```

而 Dock 窗口是**居中**摆放的。宽度一旦超过屏幕，不是左边被裁，而是**两端同时被推到屏外** ——
表现就是「新打开的程序没出现在 Dock 上」。

按当前配置实测（图标 52px、间距 6px、1920 屏）：

| 图标数 | 修复前窗口宽 | 结果 |
|---|---|---|
| 16 | 1146 | 正常 |
| 28 | 1842 | 勉强 |
| **36** | **2306** | **超出屏幕 386px，两端各被推走约 190px** |
| 60 | 3698 | 只看得见中间一小段 |

### 修法

把「屏幕可用跨度」反过来当作约束，解出图标边长的上限，然后整排等比缩小。
长度对图标边长是线性的（`s × (tiles + 3.24) + 常数`），所以上限能直接算出来，不用迭代：

| 图标数 | 收缩系数 | 修复后宽度 |
|---|---|---|
| 28 | 1.000 | 1842 |
| 36 | 0.787 | 1872 |
| 44 | 0.634 | 1872 |
| 60 | 0.445 | 1872 |

下限是 0.35（再小就认不出图标了），真缩到底还装不下才允许溢出，并写一条日志留痕 ——
免得下次又把它当玄学问题查。

用 `WorkArea` 而不是整块屏幕来算，所以隐藏任务栏、多显示器时也不会算错。

## 二、Dock 上出现空白方块

重建 Dock 时走的是 `requireIcon: false`，**图标取不到也保留这一项**，于是渲染成一个没有任何
内容的圆角方块。

做了两层处理：

1. **自动重试**：图标取不到，最常见的原因是 exe 正被自己更新占用、或 Shell 图标缓存还没就绪，
   属于临时状态。重建后 1.5 秒自动重跑一次，取到了就换回正常图标。只重试一次，
   路径真的失效时不会反复重建整行。
2. **首字兜底**：重试后仍取不到，显示名字首个字符（中文取首字，英文取首字母），
   至少能看出那是哪个程序。

> 排查过程中确认过：`IShellItemImageFactory` 这条链路本身是好的 ——
> 逐个探测了当前 Dock 上全部应用的图标，128×128、`Bgra32`、全部正常取到。
> 所以问题不在取图 API，而在「取不到时没有重试、也没有兜底」。
