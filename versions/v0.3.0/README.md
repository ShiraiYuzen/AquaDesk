# AquaDesk v0.3.0

> 发布：2026-10-26 · 能看窗口了：预览、系统图标、四边停靠

## 一句话

Dock 上直接看得到每个应用的窗口缩略图；系统图标补齐；上下左右四条边都能停。

## 这一版有什么

- **窗口预览区**：用 `PrintWindow` 抓缩略图（DWM 缩略图在透明窗口上会变成黑块，所以没用）。
- **系统图标**：品牌、Windows、启动台、我的电脑、废纸篓，每个都能单独开关。
- **四边停靠**：上 / 下 / 左 / 右，竖排布局跟着换。
- **界面缩放**：整条 Dock 按比例缩放，2K / 4K 屏不会挤成一团。

## 修复

- 设了底部间距后，图标被窗口边缘裁掉。
- 预览项刷新会把所有图标重建一遍，视觉上闪一下。

## 说明

合并自内部构建 0.2.3 与 0.3.0 ~ 0.3.2。
