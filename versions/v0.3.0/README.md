# AquaDesk v0.3.0

> 发布：2026-10-26 · 产物 `AquaDesk-0.3.0.exe`（约 69.5 MB，自包含单文件）

## 一句话

把 v0.2.3 那批「能看但有毛病」的功能全部修到能用：预览有图、顺序稳定、系统图标能拖。

## 本版更新

### 变更

- 版本号由 0.2.3 重编为 0.3.0。
- **系统图标可拖**：品牌 / Windows / 启动台 / 我的电脑不再写死在头部，改为存进 `dock.json`，
  和普通图标一样能拖、能排序；**拖出 Dock = 关掉它**（自动关对应设置开关）。
- **顶部菜单栏注册为 AppBar 占位**（26px），最大化窗口从菜单栏下方开始；
  **Dock 保持浮层**，窗口一直铺到屏幕底边。
- 新增「窗口预览」开关，关掉时清空列表并撤掉两条分隔线。

### 修复

- **窗口预览全是空白**：`PrintWindow` 走 GDI 绘制、不写 alpha 通道，
  按 `Bgra32` 解析就是一张全透明图。改用 `Bgr32`。
- **预览排序随切前台乱跳**：`EnumWindows` 给的是 Z 序，改按**进程启动时间**排序，
  同进程多窗口用首次出现序号兜底。
- 浏览器切标签页导致预览项重建、缩略图白抓：`DockItem.Name` 改为可写并就地更新。
- **提权窗口**（任务管理器）抓不到图、关不掉：抓不到退回应用图标；关闭菜单置灰并改文案；
  `PostMessage` 换成 `SendMessageTimeoutW`（UIPI 拦截时 PostMessage 仍返回成功，根本发现不了失败）。
- **新版本接管旧进程失败直接退出**：`Kill(entireProcessTree: true)` 在目标进程是调用者祖先时抛异常，
  改为只杀自己。此前「改了代码但看到的还是旧版本」就是这个原因。
- **菜单栏被 Shell 挪到 y=26**：注册 AppBar 后 Shell 会把窗口重定位到预留区底部，
  WPF 的 `Top` 改不回来（赋同值是空操作）。改用 `SetWindowPos` 硬钉 + 1 秒常驻守护。
- **任务栏那 48px**：实测只有 `ABM_SETSTATE + ABS_AUTOHIDE` 能释放工作区，
  `SPI_SETWORKAREA` 会被 Shell 立刻覆盖。代价是鼠标碰底边任务栏会弹出来，
  加 120ms 守卫定时器按回去。
