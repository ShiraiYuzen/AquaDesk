# AquaDesk v0.3.1

> 发布：2026-10-26 · 产物 `AquaDesk-0.3.1.exe`（约 69.5 MB，自包含单文件）

## 一句话

Dock 不再只能贴底：上、下、左、右四边都能停，竖排也调好了。

## 本版更新

### 新增

- **Dock 四边停靠**：底部 / 顶部 / 左侧 / 右侧，设置 → 外观 → 位置切换。
  横竖差异全部收敛进 `AppSettings` 的派生属性（`IsVertical`、`DockPanelOrientation`、
  `EdgeMarginThickness`、`IconTransformOrigin` 等），视图层只做轴向分支。
- **竖排布局**：图标从上往下排，放大方向、落点索引、插入指示条全部换轴。
- 竖排运行指示条、竖排分隔线（34×1.5）都有独立样式。

### 修复

- **设了底部间距后图标被裁**：窗口高度没把 `BottomMargin` 算进去，改成 `WindowHeight + BottomMargin`。
- **竖排运行指示条不转**：`RotateTransform` 上绑 `RelativeSource` 是无效的 ——
  Freezable 不在可视树里，找不到祖先，绑定静默失败、角度一直是 0。
  改成不旋转，直接对调宽高（4×13）+ 两套动画。
- **竖排分隔线只有 13px 长**：Style 里同一属性多条触发器，后写的赢；
  而且格子只有 13 宽，34 长的横线放不下会被裁。给分隔线单独撑开格子宽度。
- **点菜单栏的托盘按钮没反应**：任务栏切成自动隐藏后 Shell 把它挪到屏幕外（y=1078，屏才 1080），
  但 `IsWindowVisible` 依然返回 true。判断条件加上「矩形是否在屏内」，
  并用 `SW_SHOW`（不是 `SW_SHOWNA`）—— 自动隐藏状态下后者只标可见、Shell 不渲染，UIA 树仍是空的。

### 变更

- 指示条的对齐与边距从绑定改回字面值 + 触发器覆盖：绑定一旦失败会静默回落到默认对齐，位置就跑偏了。

## 安装

双击 `AquaDesk-0.3.1.exe`。

## 已知问题

- 竖排路径是新代码，拖拽排序出问题优先看 `OnSurfaceMouseMove` 和 `GetDropIndex`。
- 界面缩放仍未做。

## 升级自

v0.3.0。配置新增 `Edge` 字段，缺省为底部，旧配置直接可用。
