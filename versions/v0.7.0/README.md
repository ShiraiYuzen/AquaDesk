# AquaDesk v0.7.0

> 发布：2026-11-02 · 设置里加「检查更新」，同一个版本同时提供便携版与安装版两种形态

## 一句话

设置 → 关于里多了「检查更新」：点一下比对 GitHub Releases 最新版本，有新版就列出更新内容；
便携版提示内容并一键打开发布页手动下载，安装版走 Velopack 框架一键下载安装。此外新增图形化
安装引导器（选目录）、设置页「打开安装目录」和「卸载」。

## 新增

### 检查更新（设置 → 关于 → 版本行右侧）

- 有新版：弹出卡片，列出更新内容（Release body 渲染成轻量 Markdown：**粗体**、`行内代码`、
  链接、标题、代码块）。
- 已是最新：只给「好的」。
- 检查失败：把原因写清楚（超时、GitHub 限流 403、仓库没发布版本 404、连不上），
  并提供「复制诊断信息」按钮（版本、时间、系统、每个源的请求结果，反馈时直接贴）。

### 两种形态（同一版本、同一份源码）

| 产物 | 更新方式 | 适合谁 |
| --- | --- | --- |
| `AquaDesk-0.7.0.exe`（便携版，单文件） | 提示更新内容 + 一键打开发布页 + 附 SHA256 手动核对 | 绿色软件党 / 极客 |
| `AquaDesk-win-Setup.exe`（安装版，Velopack） | 一键下载并安装，delta 更新、后台校验签名、自动重启 | 普通用户 |

两者都用编译符号 `VELOPACK` 区分，共用同一张自签证书（指纹 `62DF52A9…`）。

### 图形化安装引导器

独立小工具 `AquaDesk.Installer.exe`（与 Setup.exe 一起打包成 `AquaDesk-0.7.0-Setup.zip`）：
弹出一个选目录的框，选好后静默调 `Setup.exe --installto "<目录>"` 装到指定位置，
补上 Velopack 原生没有的「浏览…」选目录能力。

### 设置页「维护」区（仅安装版显示）

- 「安装目录 → 打开」：直接用资源管理器打开安装根目录，不弹「已安装」窗口。
- 「卸载 AquaDesk」：确认后删除配置目录 + 调 `Update.exe --uninstall` 删安装目录 / 快捷方式 / 注册表项。

### 可靠性

- **多源回退**：`api.github.com` → `ghproxy.net` → `gh-proxy.com` 顺序试，
  国内网络不至于「永远连不上 GitHub」。
- **版本比较用 semver**：正确处理 `v0.7.0-rc1` 这类预发布标签，不再被 `Version.Parse` 截断误判。
- **「跳过这个版本」**：卡片左下角勾选，状态单独存 `update-state.json`（不随 settings.json 重置而丢）；
  勾了之后静默检查也不再提醒。
- **后台静默检查**：启动 12 秒后悄悄查一次，有新版本时「关于」页按钮直接显示「有新版本 x.y.z」，
  不弹窗打扰。

### 顺手修的

- 「关于」页版本号原来读 `AssemblyVersion`（0.4.12.0，Win32 文件版本用，一直没跟着发版改），
  现在读 `InformationalVersion`（0.7.0）。
- Dock 空白处右键菜单补上「Dock 设置…」——之前把品牌图标关掉后，界面上就没有任何入口能打开设置页。
- `--settings` 启动参数：直接打开设置页。

## 验证

便携版：

```powershell
powershell -ExecutionPolicy Bypass -File .\verify_release.ps1
```

应显示 `[2/3] 签名证书指纹可信（v0.6.4 起）`。

安装版（Setup.exe）同样用 `62DF52A9…` 这把证书签的 Authenticode，可直接用
`Get-AuthenticodeSignature` 核对指纹。
