# AquaDesk v0.6.0

> 发布：2026-11-01 · 对应内部构建 0.4.20 + 0.4.21 · 功能版：窗口预览按应用合并

## 一句话

Dock 中间的窗口预览按应用合并：同一应用的 N 个窗口合成一张预览 + 角标，
点开弹窗口列表，还能一键关闭全部窗口。开多少窗口，Dock 宽度都恒定。

## 背景

窗口预览区原来按窗口逐个排，最多放 6 个窗口。窗口一多：要么被截断
（看不到后面的窗口），要么把 Dock 撑得老长。参考 macOS Dock 的做法做了合并。

## 新增

### 按应用合并

- 同一个 exe 的多个窗口合并成一张预览，代表窗口取组内最早启动的那个
  （缩略图、标题、右键菜单都认它）。
- 预览右上角**角标**显示组内窗口数（单窗口不显示）。
- 预览格数以「应用数」封顶（仍为 6），Dock 宽度可预测。
- exe 路径读不到的窗口（个别提权进程）按句柄独立成组，不会被误合并。

### 窗口列表 + 关闭所有窗口

- 点合并预览弹出该应用全部窗口的标题列表，点哪条切到哪个窗口（最小化的自动还原）。
- 列表末尾新增「**关闭所有窗口**」：对组内每个窗口逐个发 `WM_CLOSE`
  （被 UIPI 拦的走系统菜单 `SC_CLOSE` 降级）。有未保存文档的应用会弹保存确认框，
  不会被强杀。
- 菜单挂在 NOACTIVATE 的 Dock 上，与右键菜单同一套看门狗：在菜单外面按下鼠标就收起。

## 不变的部分

- 缩略图仍为静态抓图（`PrintWindow`），作用于组内代表窗口。
- 右键菜单「切换到该窗口 / 关闭窗口」作用于代表窗口。
- 窗口集合没变时只同步标题、不重建（浏览器切标签页不会闪）。

## 版本号说明

本版本由内部构建 0.4.20 与 0.4.21 归并而来。
