# AquaDesk v0.6.0

> 发布：2026-11-02 · 能自己更新了：签名发布、安装版、检查更新

## 一句话

设置 → 关于里多了「检查更新」；同一个版本同时提供便携版与安装版；发布物全部签名，
可以用一条命令验证是不是作者发的。

## 这一版有什么

### 检查更新（设置 → 关于）

- 有新版：弹卡片列出更新内容（Release 正文渲染成轻量 Markdown）。
- 已是最新 / 检查失败：分别给提示，失败时写清原因（超时、限流、连不上），可一键复制诊断信息。
- 「跳过这个版本」：状态单独存 `update-state.json`，不随设置重置而丢。
- 启动 12 秒后静默检查一次，有新版时按钮直接显示「有新版本 x.y.z」，不弹窗打扰。

### 两种产物（同一版本、同一份源码）

| 产物 | 更新方式 | 适合谁 |
| --- | --- | --- |
| `AquaDesk-0.6.0.exe`（便携版，单文件） | 提示内容 + 一键打开发布页，附 SHA256 手动核对 | 绿色软件党 |
| `AquaDesk-win-Setup.exe`（安装版，Velopack） | 一键下载安装，delta 更新、自动校验签名、自动重启 | 普通用户 |

另有图形化安装引导器（选目录安装；已装过时给「打开目录 / 卸载」），
设置页多一块「维护」区（仅安装版显示）。

### 可验证的发布

自签名证书 + `SHA256SUMS.txt` + 分离签名 `.sig` + `SIGNING.txt`，
`verify_release.ps1` 一条命令做三层校验（哈希 → 证书指纹 → 清单签名）。

### 其它

- 窗口预览按应用合并（多窗口只占一格，角标记数），点开是「应用 → 窗口」列表，
  末尾有「关闭所有窗口」；预览区按 Dock 宽度动态定格，装不下时留「全部窗口」入口。
- 隐私边界：声明了捕获保护的窗口不抓缩略图，密码类应用按 exe 名兜底，
  另有「预览只显示图标」开关。
- 输入法面板列出全部已安装输入法并支持直接切换。
- Dock 图标过多时整排等比缩小，不再被挤出屏幕。

## 修复

- 崩溃 / 强杀后任务栏留在隐藏态（四条退出路径都还原 + 标记文件兜底 + `--restore`）。
- 图标取不到时留白方块（名字首字兜底 + 1.5 秒后重试一次）。
- 菜单点别的应用后不关闭；菜单被状态胶囊压住；菜单分割线不居中。
