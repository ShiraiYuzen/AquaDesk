# AquaDesk v0.4.3

> 发布：2026-10-31 · 产物 `AquaDesk-0.4.3.exe`（69.6 MB，自包含单文件）· 后续版本见 [v0.4.8](../v0.4.8/README.md)

## 一句话

一个下午连着做了十二版：界面退回原生窗口、抓屏折射下线、托盘模块删除、
顶部胶囊会显示正在播放、设置页重排成五类、右侧状态胶囊从 Dock 手里接过系统入口，
最后连图标都重画了一遍。

## 这一版之前，界面和现在差得挺远

0.3.3 那个版本，Dock 是靠「抓屏折射」做出玻璃感的 —— 每帧抓一次 Dock 背后的画面，
做边缘弯折。效果确实漂亮，代价是**用户任何截图、录屏都拍不到 Dock**
（折射要求把自己从屏幕捕获里排除，`WDA_EXCLUDEFROMCAPTURE`）。

这两个需求互斥，只能二选一。这次选「能截图」，折射整块下线。
现在玻璃底下没有真实背景弯折了，只剩「半透明底色 + 多层高光」——
静态看差别不大，动起来（拖窗口从 Dock 后面经过）会少一点味道，这是明说的取舍。

## 主要变化

### 布局：一条 Dock 管应用，右侧胶囊管系统

Dock 最左边原来挤着两个固定图标（四格 Windows 标志、AquaDesk 品牌图标），
应用图标一多就得横向找。现在它们搬到了右侧的状态胶囊：

```
上排  设置 · Windows · 后台程序 · 电量 · WiFi
下排      蓝牙 · 音量 · 输入法状态 · 键盘布局
```

胶囊里所有图标按 **27px 的列网格**排：上排 5 项占 6 格（电量那块宽，占两格），
下排 4 项占 4 格居中 —— 正好偏 1 整格，上下严格对齐。
**分行是算出来的**：偶数上下对半、奇数上排多一个下排居中，
所以关掉「后台程序」按钮（只剩 8 个图标）时会自动变成上 4 下 4。

### 顶部胶囊会显示「正在播放」

接系统媒体会话（SMTC），有歌在放时时间胶囊会拉宽成灵动岛形态：
播放器图标 + 曲名歌手 + 上一首 / 播放暂停 / 下一首（全部自绘），没在放就退回时钟。
轮询 600ms，不用事件——事件从 COM 线程来，切歌和关应用有竞态。

### 后台程序面板（替代系统托盘）

原来胶囊上有个 ⌄ 按钮去点系统托盘，实测**走不通**：任务栏被这个工具藏起来之后，
它的 UI Automation 树是完全空的（0 个节点），`ShowWindow` 也叫不醒。所以整个托盘模块删掉，
换成把托盘真正干的两件事拆开做：

- **切回程序**：`EnumWindows` 枚举最小化/被盖住的窗口，点一行就 `SW_RESTORE` + 置前
- **认出谁在托盘里**：读 `HKCU\Control Panel\NotifyIconSettings`，拿 `ExecutablePath` 匹配进程

几个必要的过滤（少一条列表就变垃圾场）：只认有标题栏的窗口、拿不到 exe 路径的直接跳过、
按 exe 名字聚合（豆包一个程序 14 个进程）、排除自己。

### 设置页重排成五类

外观 / Dock / 图标 / 系统 / **关于**（新增）。每页内部再分节，卡片、节标题、侧栏图标
统一一套视觉规则。窗口给了 `MaxWidth=1040 / MaxHeight=860`，系统「最大化」改成
「放大到最大尺寸并居中」——否则标题栏会被顶出屏幕。

### 电池百分比默认不显示了

和 macOS 一样只画电池图形（充电闪电、≤20% 变红都在）。想要数字去
设置 → 图标 → 状态胶囊打开，打开后电量占两格、胶囊会自己变宽。

## 应用图标重做

上一版是「胶囊 + 三个等大方块」，缩到 16px 只剩三个点，容易被当成「更多菜单」。
新版是「玻璃 Dock + 四个应用图标」，方块底边对齐地坐着，第三个放大并微微上浮 ——
就是 Dock 悬停放大的样子。纯几何绘制（`tools/make_icon.py`），没有 AI 生成的杂边。

## 升级注意

配置会自动迁移，不用手动改 `%AppData%\AquaDesk\settings.json`：

- `SettingsVersion` 升到 2：老配置里 Dock 上的 Windows / AquaDesk 两个图标会被关掉（入口已在胶囊上）
- 电池百分比是新字段，默认关

## 几个值得记下来的坑

1. **无边框透明窗口的根元素一定要有 `Background`**。液态透明玻璃下那层白底是隐藏的，
   只靠装饰矩形（都设了 `IsHitTestVisible=False`）撑不起命中区 —— 鼠标滑到图标空隙就判定
   「离开窗口」→ 放大复位 → 再进入，整条 Dock 疯狂闪。实测一次扫过触发 9 次。
2. **别拿窗口矩形反推内部控件的矩形**。中间隔着「预留余量 / 内边距 / 居中 / DPI 换算」，
   算出来的边会偏三四十像素。`PointToScreen` + `ActualWidth` 拿真实矩形，比公式可靠。
3. **`Border` 没有 `Fill`**，只有 `Background`（MC3072），小图标里画实心块时会踩。
4. **会改变元素宽度的开关，不能只切 `Visibility`**：还得通知做布局的那层重算格子，
   否则关掉电池百分比之后右边图标全错位。
5. **`SetWinEventHook` 的事件范围一定要收到单点**，写 `0x8001~0x800B` 会把系统所有对象事件
   收进来，UI 线程直接拖死；回调里必须整段 try/catch，异常冒出去就是进程秒退、日志一片空白。
