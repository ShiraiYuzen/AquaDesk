# AquaDesk v0.1.0

> 发布：2026-10-20 · 第一个能日常用的版本：一条会放大的 Dock

## 一句话

把 macOS 的 Dock 搬到 Windows：图标铺满、悬停放大、拖放排序，单文件 exe 双击即用。

> **本版没有二进制附件**：这一阶段的构建产物在早期「只留最近几个」的清理里删掉了，
> 而且重排前项目还没有版本控制，源码补不回来。这里保留的是功能说明。

## 这一版有什么

- **Dock 本体**：图标横向铺开，悬停时放大并让邻居往两边让位，运行中的应用下方有指示条。
- **拖放**：从桌面或开始菜单拖进来添加图标，拖动排序，拖出移除。
- **右键菜单**：打开 / 关闭应用 / 添加应用… / 新建文件夹 / 移除此图标。
- **单文件自包含**：一个 exe（约 63 MB），目标机器不需要装 .NET。

## 说明

合并自内部构建 0.0.1 与 0.2.0 的 Dock 主体部分。
