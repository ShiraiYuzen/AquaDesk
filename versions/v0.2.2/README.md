# AquaDesk v0.2.2

> 发布：2026-10-26 · 产物 `AquaDesk-0.2.2.exe`（约 69.5 MB，自包含单文件）

## 一句话

Dock 从「一排应用」变成能装东西的桌面工具：文件夹、我的电脑、按条件暂停。

## 本版更新

### 新增

- **Dock 文件夹**：右键「新建文件夹」、拖应用进文件夹、文件夹右键「添加文件…」/「重命名」。
  图标是白色圆角块 + 2×2 缩略图，空文件夹画轮廓。
- **文件夹窗口**：点开是独立窗口，视觉照搬启动台（暗色径向底、7 列网格、74px 图标、搜索、Esc 关闭），
  支持直接滚动，不分页。
- **我的电脑**：矢量显示器图标，固定在启动台右边，左键打开 `shell:MyComputerFolder`。
- **设置页红绿灯**：左上角改成 macOS 三色按钮（关闭 / 最小化 / 缩放），悬停才显示字形。
- **按条件暂停后台工作**：不暂停 / 其他应用成为焦点时 / 无边框全屏时 / 全屏时（含 F11）。
  暂停时停掉折射与轮询、释放缓冲、压工作集；鼠标回到 Dock 立刻恢复。
- 设置 → 外观 → 图标新增「我的电脑」开关。

### 变更

- Windows / 我的电脑 / 废纸篓三个图标统一成磁贴底板风格（浅色砖 + 左上柔光），
  按字形在 100 单位里的实际占比反算 Viewbox 尺寸，视觉重量才对得上。
- `DockItem.IsPinned` 改为 `Kind is not (App or Folder)` —— 文件夹是用户项，要能拖能删。
- `Remove()` 从「按 Target 匹配」改成「按索引」：文件夹 Target 是空串，按路径会误删。
- `dock.json` 新增 `IsFolder` / `Items` 两个字段都带默认值忽略标记，**应用项的 JSON 格式完全不变**。

### 修复

- 红绿灯字形没居中：`Path` 不给尺寸时按几何原始坐标摆放，必须显式尺寸 + `Stretch=Uniform`。
- 最小化后点 Dock 图标窗口不回来：对最小化窗口调 `Activate()` 只会闪一下任务栏。
- 设置页开着时点图标不最小化：前台状态判断在这个场景不可靠，最终改成**纯切换语义**
  （最小化就还原、否则最小化），行为确定，不会失败。
- 设置页最大化后四边露出桌面：`Margin`、`Effect`、三处圆角必须一起改。
- 文件夹窗口里增删项目后不能重读 `_folder.Children`（那是打开时的快照），
  否则刚加的消失、刚删的复活。

## 安装

双击 `AquaDesk-0.2.2.exe`。
