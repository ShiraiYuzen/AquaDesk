# AquaDesk v0.6.6

> 发布：2026-11-01 · 窗口预览区从「写死 6 格」改成「按可用宽度动态定格 + 溢出折叠」

## 一句话

开很多应用时，预览区不再悄悄把第 7 个应用「吃掉」——现在按 Dock 实际能用的宽度动态决定放几张预览，
实在放不下就收进末尾一个「全部窗口」入口，点开是「应用 → 窗口」两级菜单。

## 原因

原来 `WindowPreviewService.MaxPreviews = 6` 是**写死的截断**：第 7 个应用起既没有预览，
也没有任何入口能点到它，等于这些窗口在 Dock 上「消失」了。

## 修法

- `DockWindow.ComputePreviewSlots()` 用 `WorkArea - 非预览项占用` 反解还能排几格，
  clamp 到 `[3, 12]`（12 是性能上限，一屏十几张 `PrintWindow` 顶不住）。
- 故意用**未缩放**的图标尺寸来算，避免「格数变大 → 缩图标 → 又能放更多格」来回抖。
- 溢出时把最后一格留给「全部窗口」入口（`DockItemKind.WindowList`，3×3 白点 + 琥珀色角标，
  角标数字 = 被折叠的应用数），点开是「应用 → 窗口」两级菜单；单窗口应用平铺成一条、不套二级。

按 exe 合并依旧生效：同一个应用开多少窗口只占 1 格，只在角标上记数。
