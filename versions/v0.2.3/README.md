# AquaDesk v0.2.3

> 发布：2026-10-26 · 产物 `AquaDesk-0.2.3.exe`（约 69.5 MB，自包含单文件）

## 一句话

Dock 里能直接看到窗口缩略图，点一下就切过去。

## 本版更新

### 新增

- **Dock 窗口预览区**。布局变成
  `[系统图标][应用] [分隔线] [窗口预览…] [分隔线] [废纸篓]`，没有预览时退回单分隔线。
- 预览最多显示 6 个窗口，点击三态：已最小化 → 还原并切前台 / 在前台 → 最小化 / 否则切前台。
- 预览项独立右键菜单：切换、关闭窗口。
- 设置 → 外观 → 图标新增「窗口预览」开关。

### 实现要点

- 抓图用 `PrintWindow(PW_RENDERFULLCONTENT)`，**不用 DWM 实时缩略图** ——
  Dock 是 `AllowsTransparency` 的透明窗口，DWM 缩略图必须挂在子窗口上，会被画成不透明方块、圆角也没了。
- 缩放放在 GDI 里做（`StretchBlt` + `HALFTONE` 缩到 96×60 再 `GetDIBits`），
  否则每个 1080p 窗口每次刷新都要在托管侧分配 8MB 缓冲。
- 缩略图放后台 `Task` 抓，`_capturing` 防重入；鼠标不在 Dock 上时只补新窗口，不整体重抓。

### 修复

- 预览项不能走完整 `Rebuild()`（会把所有应用图标重新取一遍），新增 `RebuildTail()` 只重建尾部。
- `AppCount` 改为只数 `IsApp || IsFolder`，否则预览会被算成用户图标、拖放索引全乱。
- `UpdateWindowWidth` 简化成「数磁贴 + 数分隔线」，以后加减区块不用再改公式。

## 安装

双击 `AquaDesk-0.2.3.exe`。

## 已知问题

- 预览排序会随切前台变化。
- 提权窗口（任务管理器）抓不到图、也关不掉。
