# AquaDesk v0.2.0

> 发布：2026-10-21 · 玻璃、启动台、文件夹，Dock 之外的东西开始长出来

## 一句话

Dock 背后那层玻璃变成真的会折射的玻璃；启动台、我的电脑、文件夹、WiFi/蓝牙/音量面板全部就位。

> **本版没有二进制附件**：这一阶段的构建产物在早期「只留最近几个」的清理里删掉了，
> 而且重排前项目还没有版本控制，源码补不回来。这里保留的是功能说明。

## 这一版有什么

- **真折射液态玻璃**：抓屏采样 + 边缘形变，Dock 背后的画面会随玻璃弯折，不是单纯半透明。
- **启动台**：全屏网格、搜索、分页、文件夹、拖入。
- **我的电脑 / Dock 文件夹**：文件夹里既能放程序也能放文件。
- **系统面板**：WiFi（列表 + 密码输入）、蓝牙（设备列表）、音量（拖拽调节）。
- 设置页左上角换成 macOS 三色窗口按钮。

## 修复

- 面板里改完音量 / 连上 Wi-Fi 后，图标要等下一轮定时器才刷新。

## 说明

合并自内部构建 0.2.1 与 0.2.2。
