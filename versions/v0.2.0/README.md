# AquaDesk v0.2.0

> 发布：2026-10-21 凌晨 · 产物 `AquaDesk-0.2.exe`（约 63.4 MB，自包含单文件）

## 一句话

从「一条玻璃 Dock」长成「一整套桌面外壳」：启动台、菜单栏、废纸篓、系统集成全部到位。

## 本版更新

### 新增

- **真折射液态玻璃**：采样 Dock 背后的桌面内容再模糊贴回，玻璃会「弯」后面的画面。
  同时保留「经典」风格可切换。
- **启动台**：全屏网格、搜索框、分页、文件夹、拖入、左上角「退出 (esc)」按钮。
- **顶部菜单栏**：前台应用名、时钟、电量（闪电画在电池内部，低于 20% 变红示警）。
- **废纸篓**：三态点击（无窗口 → 打开、有窗口 → 最小化、后台 → 提前台），带运行指示。
- **分隔线 + 品牌图标**，Dock 结构变成 `[系统图标][应用] [分隔线] [废纸篓]`。
- **拖放添加**：从资源管理器拖 exe / 快捷方式到 Dock 直接加图标。
- **拖动排序、拖出移除**，带跟手动画与落点提示。
- **运行指示条**：应用在跑时图标下方出现小横条，长度有动画。
- **系统集成**：开机自启（Run 键）、彻底隐藏原生任务栏、隐藏桌面图标。
- **单实例 + 托盘常驻**：重复启动时新进程接管旧进程，不用先去托盘退出。

### 修复

- 排序后悬停放大失效（索引没跟着重排）。
- 拖动后图标重叠（落点计算用了旧索引）。
- 拖拽浮层被屏幕边界裁切。

## 安装

双击 `AquaDesk-0.2.exe`。设置页可从 Dock 最左边的品牌图标进入。

## 已知问题

- 菜单栏还没有 WiFi / 蓝牙 / 音量 / 输入法面板，只有一个应用名和时钟。
- 启动台会扫进 Node、Git Bash、MySQL Shell 这类工具和运行时。
- 隐藏任务栏后点菜单栏的托盘按钮没反应。

## 升级自

v0.0.1。配置文件在 `%AppData%\AquaDesk\`，旧配置可直接沿用。
