# AquaDesk v0.4.12

> 发布：2026-10-31 · 对应内部构建 0.4.12 + 0.4.13 · 修复为主，附带灵动岛首版

## 一句话

两轮稳定性修复（任务栏恢复、输入法切换），同时上线灵动岛（顶部时间胶囊）首版：
有媒体会话时自动拉长成播放器。

## 修复

### 关闭「隐藏原生任务栏」后任务栏回不来

Win11 下任务栏处于自动隐藏状态时，Shell 会收起 Start / MSTaskListWClass 子窗口；
恢复时只 `ShowWindow` 容器本体，子窗口回不来 —— 表现就是任务栏只剩右下角托盘。
修复分两轮：

1. 恢复顺序改为「先 `SetState(ABS_ALWAYSONTOP)` 再逐个 `EnumChildWindows` + `SW_SHOW`」，
   把开始按钮和图标列表一个个请回来。
2. 追加兜底定时器，防止个别环境下子窗口仍未恢复。

### 点胶囊切换输入法没反应

两个根因：

- `WM_INPUTLANGCHANGEREQUEST` 应发给「焦点窗口」而非前台窗口 ——
  面板点击后焦点被抢到 Popup 上，发给前台窗口等于发给 Dock 自己。现在打开面板前
  记录焦点窗口（`CaptureSwitchTarget`），切换时发给它并带 `wParam=1`。
- 面板行按钮会抢焦点，改 `Focusable=false`。

## 新增：灵动岛首版

顶部时间胶囊在检测到媒体会话（SMTC）时自动拉长成播放器：
应用图标 + 曲名 / 歌手 + 上一首 / 播放暂停 / 下一首。
Spotify、网易云、QQ 音乐、浏览器里放的歌都能识别，切歌自动跟上。

设置页新增「灵动岛」分组：显示开关、固定位置开关、时间形态宽高自定义、恢复初始位置。

## 版本号说明

本版本由内部构建 0.4.12 与 0.4.13 归并而来（0.4.13 是同一任务栏 bug 的第二轮修复）。
