# AquaDesk v0.0.1

> 发布：2026-10-20 · 产物 `AquaDesk-0.01.exe`（约 63 MB，自包含单文件）

## 一句话

第一个能发给别人的包：桌面底部出现一条会发光的玻璃 Dock。

## 本版内容

### 新增

- **透明无边框 Dock 窗口**：`WS_EX_NOACTIVATE` + `WS_EX_TOOLWINDOW`，常驻桌面不抢焦点。
- **液态玻璃初版**：多层渐变叠加（tint、顶部聚光、顶边亮线、底部反光），还没有真折射。
- **图标增删**：右键菜单添加/移除，自动从开始菜单与桌面快捷方式取图标。
- **设置页**：玻璃透明度、图标尺寸、圆角可调。
- **铺满布局**：图标数量变化时自动撑开，悬停放大时邻居自动让位。
- **单文件打包**：`dotnet publish` 自包含发布，目标机器不用装 .NET。

### 修复（同日迭代）

- 左侧图标跑到玻璃条外面、右侧留白过多。
- 重启后布局恢复成初始状态（配置没落盘）。
- 圆形图标不补角、多余的「+」按钮去掉。

## 安装

双击 `AquaDesk-0.01.exe`。退出走托盘右键菜单。

## 已知问题

- 玻璃是「假」的：只是半透明叠色，不折射桌面内容。
- 没有顶部菜单栏、没有启动台、没有系统集成（自启 / 任务栏 / 桌面图标）。
- 图标取的是 32px，放大后偏糊。

## 构建

本版源码未单独归档（当时没有版本控制）。用仓库 `src/` 的当前源码可构建出功能超集版本，
构建方式见仓库根目录 `README.md`。
