# AquaDesk v0.2.1

> 发布：2026-10-21 · 产物 `AquaDesk-0.2.1.exe`（约 69.5 MB，自包含单文件）

## 一句话

菜单栏真正能用起来了：WiFi、蓝牙、音量、输入法四个面板全部打通。

## 本版更新

### 新增

- **WiFi 面板**：扫描附近网络、点选连接、加密网络弹密码输入，底部「更多 WiFi 设置」。
  实现走 `Windows.Devices.Radios.Radio`（和 Win11 设置里那个开关同一套），**不需要管理员权限**。
- **蓝牙面板**：开关、已保存设备（带连接状态）、新设备发现、配对、刷新。
  新设备先读系统缓存 `FindAllAsync` 再挂 `DeviceWatcher`，否则面板会空等广播。
- **音量面板**：播放/录音设备单选、自绘音量条，拖动直接调主音量。
- **输入法切换**：中英键盘布局一键切换。
- **启动台应用判定**：可执行文件黑名单 + **PE 头 Subsystem 判断**（`IMAGE_SUBSYSTEM_WINDOWS_CUI`
  一律跳过），本机从 32 个降到 23 个纯应用。

### 修复

- **WiFi 关不掉**：Killer AX1675i 这类网卡驱动不支持旧接口的软件射频控制
  （`WlanSetInterface` 返回 87，结构体尺寸完全对得上，就是驱动不认）。
  改用 Radio Manager 后一次成功。代价是 TFM 要升到 `net8.0-windows10.0.19041.0`，
  体积从 63.4 MB 涨到 69.5 MB。
- **隐藏任务栏后托盘按钮失效**：任务栏被 `SW_HIDE` 之后，UIA 连 `Shell_TrayWnd` 的子孙节点
  都不返回，找不到「隐藏的图标」按钮。改为「亮一下任务栏 → Invoke → 轮询等弹出层出现 → 藏回去」，
  全程 223ms，任务栏只闪一下。
- 升级换文件名后开机自启还指着旧 exe：新增 `EnsureCurrentPath()`，启动时静默校正路径。

### 变更

- WiFi 状态文案统一提到空列表分支之前算，不再卡在「正在扫描…」。

## 安装

双击 `AquaDesk-0.2.1.exe`。

## 已知问题

- **内存偏重**：工作集约 325 MB、私有约 200 MB、36 线程、约 1160 句柄。
  来源是 WPF + CsWinRT 投影 + 自包含运行时，暂无优化计划。
- 启动台扫描仍会漏进少量系统自带应用（媒体播放器、Game Bar、XBOX）。
- Dock 只有底部一种停靠位置，窗口预览还没做。

## 升级自

v0.2.0。配置文件兼容，无需手动迁移。
