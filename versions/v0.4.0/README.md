# AquaDesk v0.4.0

> 发布：2026-10-31 · 顶部菜单栏整个换掉：灵动岛 + 右侧状态胶囊

## 一句话

顶部那条 26px 的菜单栏没了，换成居中的时间胶囊；电量 / WiFi / 蓝牙 / 音量 / 输入法
搬到 Dock 右侧的小胶囊里；外观可以切换了。

## 这一版有什么

- **顶部灵动岛**：只保留时间，透明玻璃、水平居中、不占工作区（窗口可以铺到屏幕顶边）、
  点击穿透（点它等于点到底下的窗口）。
- **状态胶囊**：托盘、电量、WiFi、蓝牙、音量、输入法迁到 Dock 右侧，面板改为向上弹。
- **外观切换**：默认统一用一种外观，设置里打开「允许切换外观」后才出现其它风格。
- **设置页重做**：左侧分类 + 右侧卡片，配色跟着当前外观走。
- 系统托盘模块下线（任务栏被隐藏后它没有意义）。

## 修复

- 关掉开机自启后仍然每次开机自启（注册表 Run 键改为按名字模糊匹配）。
- 悬停 Dock 时整条闪动。
- 状态胶囊被 Dock 压住、比 Dock 高出一截。

## 说明

合并自内部构建 0.3.3 ~ 0.3.11。
