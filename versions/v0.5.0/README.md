# AquaDesk v0.5.0

> 发布：2026-11-01 · 灵动岛完整形态，Dock 之外多了一块「系统区」

## 一句话

顶部胶囊开始显示正在播放的音乐；状态胶囊排成规整的网格；后台程序有了专门的面板；
前台窗口最大化时三个浮层会自动让开。

> **本版没有二进制附件**：这一阶段的构建产物在早期「只留最近几个」的清理里删掉了，
> 而且重排前项目还没有版本控制，源码补不回来。这里保留的是功能说明。

## 这一版有什么

- **灵动岛完整形态**：有媒体会话时横向拉长，显示「应用图标 + 曲名 / 歌手 + 上一首 /
  播放暂停 / 下一首」；可拖动（拖动全程跟手）、播放形态宽高可独立调、位置可保存与恢复。
- **状态胶囊**：托盘 / 电量 / WiFi / 蓝牙 / 音量 / 输入法排成列宽网格，图标多时自动分行，
  宽度跟内容自适应。
- **后台程序面板**：列出窗口程序与托盘程序，点行切前台、右键关窗口、每行可结束进程（两步确认）。
- **浮层 z 序让位**：前台窗口最大化 / 全屏时，三个浮层自动沉到最底，还原后抬回最前。
- 设置页：窗口层级三档下拉、每页独立的「恢复本页默认」、保存按钮。

## 修复

- 状态胶囊在 WPS 这类「焦点在子窗口」的最大化应用下不沉底。
- 后台程序面板漏掉当前前台的那个程序。
- 图标分行错位；胶囊宽度不跟内容。
- 输入法状态和键盘布局挤在同一格里。

## 说明

合并自内部构建 0.4.0 ~ 0.5.0。
