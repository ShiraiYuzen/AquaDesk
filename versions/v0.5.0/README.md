# AquaDesk v0.5.0

> 发布：2026-11-01 · 对应内部构建 0.4.15 ~ 0.4.19 · 功能版：灵动岛完整形态

## 一句话

灵动岛一轮完整打磨：拖动全程跟手、播放形态也能拖、播放形态宽高可调；
顺带修掉状态胶囊在 WPS 下不沉底的老毛病。

## 新增

### 拖动全程跟手

原先用相对窗口的坐标记录拖动基准，窗口一移动基准就漂 —— 表现为「拖一下就卡住、
越拖越偏」。`GetPosition(null)` 在 Window 上和 `GetPosition(this)` 等价，都是相对窗口，
所以第一次替换没起效；最终改用 `PointToScreen` 转屏幕绝对坐标，与 `Left/Top` 同一
坐标系，无论窗口怎么动基准都不变，200 步模拟每一步都精确命中。

### 播放形态可拖动

播放形态不再禁拖。三个播放控制按钮（上一首 / 播放暂停 / 下一首）沿视觉树识别，
点按不误触发拖动、照常响应；胶囊其余区域可拖。

### 播放形态宽高可调

播放时胶囊自动拉长到 256×34（基准），现在在此之上开放独立调节：
宽 150~500 px、高 24~100 px，曲名放不下自动省略号。改动实时生效；
「恢复初始位置」一并还原播放形态尺寸（原 0.4.19 修的三处重置漏项）。

## 修复：状态胶囊在 WPS 等最大化窗口下不沉底

WPS 这类多窗口应用把键盘焦点留在子窗口 / 悬浮窗上，真正放大的文档窗口不是
前台窗口 —— 原来只查前台窗口的判定永远不触发沉底，状态胶囊一直压在内容上。

两层修复：

1. 前台窗口未放大时，退一步查同进程是否有放大的顶层窗口（按 `IsZoomed` 直判。
   不叠加「盖满整个显示器」的要求 —— 原生任务栏可见时最大化窗口底部会留约 40px
   间隙，矩形比较会漏判）。
2. 沉底期间 `FollowDock` 不再把胶囊顶回 `HWND_TOPMOST`。
