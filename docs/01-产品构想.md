# 01 · 产品构想与竞品调研

## 一、用户是谁

不是「想让电脑好看一点」的普通用户，而是这三类：

1. **被迫用 Windows 的 mac 用户** —— 公司配的机器是 Windows，习惯改不掉，天天在找「把 Windows 变成 mac」的工具。
2. **审美敏感的技术人** —— 受不了 Windows 11 的圆角半成品和广告位，愿意花时间折腾主题。
3. **双系统 / 虚拟机用户** —— 在 mac 上用 Parallels 跑 Windows，希望两边视觉统一，不割裂。

共同点：**能接受装第三方常驻程序，愿意为「顺手」付费，但极度反感流氓软件行为**（弹窗、捆绑、偷数据）。

## 二、竞品在做什么

| 产品                    | 形态          | 强项                                     | 短板                                    |
| --------------------- | ----------- | -------------------------------------- | ------------------------------------- |
| **MyDockFinder**      | 付费（Steam）   | 国内最成熟的仿 mac 方案，Dock + 顶部栏 + 启动台都有，细节到位 | 视觉偏「拟物复古」，用的是老 mac 风格；更新慢；只支持 Windows |
| **Nexus Dock**        | 免费 + 付费 Pro | Dock 做得扎实，皮肤多                          | 只做 Dock，不管菜单栏和窗口效果，割裂感强               |
| **Rainmeter**         | 免费开源        | 无限可定制，皮肤生态庞大                           | 学习曲线陡，本质是「桌面挂件引擎」，不是「系统壳替换」           |
| **StartAllBack**      | 付费          | 专注任务栏 / 开始菜单改造，稳定                      | 只改系统组件，不改交互逻辑                         |
| **Ubuntu / Linux 桌面** | ——          | 开源可控                                   | 换系统的代价太大，不是同一赛道                       |

**结论**：市场不缺「单点工具」，缺的是**一套视觉与交互都统一的完整体验**。  
现有产品的通病是：Dock 是 Dock、菜单栏是菜单栏、窗口还是 Windows 的方角——拼起来像 cosplay，不像原装。

## 三、我们的差异点

**① 一致性优先**  
Dock、菜单栏、窗口圆角、字体、动效节奏，全部来自同一套设计 token（圆角半径、阴影层级、动画曲线、间距栅格）。  
不是「每个模块各做各的」，而是先定义一套 `Aqua Design Token`，所有模块从它取值。

**② 尊重 Windows 的里子**  
不做系统注入、不替换 explorer.exe、不劫持系统 DLL。  
只用官方 Win32 API + DWM 合成器做「表层覆盖」，工具崩了大不了退出，不会带走用户的桌面。

**③ 性能是功能**  
常驻进程的内存预算：**空闲 < 60MB，动画峰值 < 120MB**。  
Electron 方案直接出局——一个美化工具比被美化的系统还重，是原罪。

**④ 可逆**  
一键「完全恢复原状」，包括任务栏、字体、注册表项、开机自启。  
卸载后不留垃圾，这是对用户的基本尊重。

## 四、不做什么（划清边界）

- ❌ 不做「主题商店 + 内购」的商业模式，先做工具，不谈变现
- ❌ 不碰系统文件、不注入进程、不要求管理员权限常驻
- ❌ 不做壁纸站（已有太多），只做壁纸「适配」（按屏幕比例裁切、动态壁纸可选）
- ❌ 不支持 Windows 10 以下版本，Win10 21H2+ 起步
