### Project description

```
AquaDesk is a Windows desktop shell replacement written in C# / WPF on .NET 8.
It provides a macOS-style Dock, a top status capsule (clock / now-playing),
a right-side system capsule (battery, Wi-Fi, Bluetooth, volume, input method),
a launchpad, window previews and desktop-adjacent integrations
(hide native taskbar, hide desktop icons, autostart).

Target users are Windows 10/11 users who want a macOS-like desktop experience.
The app runs with asInvoker (never elevates), makes no network requests,
has no third-party dependencies, and stores its settings as local JSON files.

We distribute a single self-contained .exe (no installer) via GitHub Releases.
Binaries are produced from the public repository by build.ps1, which is invoked
unchanged by the GitHub Actions workflow in .github/workflows/build.yml.
```

## 三、提交后会发生什么

1. 表单提交 → 状态 `Pending Approval`，一般几个工作日，期间可能邮件追问细节。
2. 通过后你会拿到：
   - **Organization ID**
   - **Project slug**（形如 `your-org/aquadesk`）
   - **Signing policy slug**（通常 `release-signing` 之类）
   - **API Token**
3. 把这些填进 GitHub 仓库：
   - `Settings → Secrets and variables → Actions → Secrets`：新建 `SIGNPATH_API_TOKEN`
   - 同页 `Variables`：`SIGNPATH_ORGANIZATION_ID`、`SIGNPATH_PROJECT_SLUG`、`SIGNPATH_SIGNING_POLICY_SLUG`
4. 推一个 tag 触发 `.github/workflows/build.yml`，它会在构建后自动提交签名请求。
5. 到 SignPath 控制台点 **Approve** —— 产物变成签名版，从 Actions 的 `signed` artifact 取回。

配置齐了之前，workflow 里的签名步骤会自动跳过（`vars.SIGNPATH_PROJECT_SLUG` 为空），
所以现在推上去只会正常构建，不会红。

## 四、审核最看重的两件事（已在仓库里备好）

1. **「这个二进制确实出自这个仓库」** —— 有公开的 CI workflow（`.github/workflows/build.yml`），
   跑的就是仓库里的 `build.ps1`，没有本地手工改产物的空间。
2. **「发布物可追溯」** —— 每个 Release 都带 `SHA256SUMS.txt`（0.6.1 起），
   0.6.2 起还带自签名证书与时间戳，说明我们已经在做完整性证明，只是缺一个受信的根。

## 五、签名流程示意（通过后照做）

```
tag 推送 ─→ GitHub Actions ─→ build.ps1 ─→ dist/*.exe（未签名）
                              │
                              ├─ upload-artifact: unsigned
                              │
                              └─ signpath/submit-signing-request
                                    ↓ 你在控制台点 Approve
                                  signed/AquaDesk-x.y.z.exe
                                    ↓
                              upload-artifact: signed → 手动传 Releases
```

`signpath/artifact-configuration.xml` 已经按「单文件 PE + Authenticode」写好，
首次在控制台建 Artifact Configuration 时可以直接粘。
